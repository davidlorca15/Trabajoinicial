# Primer proyecto
Este es el primer proyecto
## Aplicacion de Tareas
Un pequeño gestor de tareas `Todo listo` el diseño es a eleccion del alumno.
#### historias del usuario
- Añadir una lista
- Ver lista de tareas **pendientes**
- Marcar una tarea como completada
- Eliminar una tarea

## Implementacion
- java 27
- `Scanner` y `println` para el UI
- `Arraylist` para la lista de tareas
